## Our Projects

### OSTpe (Operating System Technology Preinstall Environment)

OSTpe is designed to optimize your PC by:

* Cleaning **Cache and Trash** and freeing storage space.
* Removing bloatware.
* Improving overall system performance and CPU efficiency.
* Providing a cleaner and more responsive computing experience.

### ORTos (Operating Re-systemize Technology)

As OSTpe nears completion, development has begun on **ORTos**.

ORTos is a **pure bare-metal operating system**, built from the ground up without relying on another operating system. The project's goal is to provide a modular, and highly customizable operating system that gives users complete control over their Desktop Environment.

Current features include:

* Display support
* Keyboard input
* GRUB bootloader support
* Basic shell (V1)

## Fixed Goal

ORTos is designed to be fully modular, allowing users to:

* Add or remove features as needed.
* Customize the operating system to fit their specific requirements.
* Build their own functionality and extensions with minimal overhead.

Our goal is to create a fast, flexible, and educational operating system that gives developers complete control over the software stack.
